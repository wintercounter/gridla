Lets items move between every [`GridProvider`](/api/qwik/provider#gridprovider) rendered inside it. The
pointer decides the target: the deepest registered canvas under the pointer
that accepts the item previews the drop; releasing there commits it. The
underlying [`TransferScope`](/api/elements/elements#transferscope) from `gridla/interaction` is created on the
client by the first provider that mounts.
