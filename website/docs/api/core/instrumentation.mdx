# Instrumentation

> Generated by `website/scripts/generate-api.ts` from `packages/gridla/src`. Do not edit by hand; run `bun run generate` in `website/`.

Optional tracing. Pass `onTrace` in [`SolveOptions`](/api/core/solvers#solveoptions) and every solve reports the strategy it used, so you can build debug overlays or log interaction paths without the core owning a logger.
