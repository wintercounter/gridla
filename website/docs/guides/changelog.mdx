# Changelog

Release notes are generated by Changesets and committed to the package:

- [`packages/gridla/CHANGELOG.md`](https://github.com/wintercounter/gridla/blob/main/packages/gridla/CHANGELOG.md) on GitHub, one section per version.
- [GitHub releases](https://github.com/wintercounter/gridla/releases), one entry per published version, with the same notes.
- The `CHANGELOG.md` shipped inside the npm package.

Each entry names the entry point (`gridla` or `gridla/react`), describes the change, and for breaking changes includes a before/after snippet under a "Breaking" heading. See [migration and versioning](./migration) for what may change in which kind of release.

## Current release

`0.1.0` is the initial public release: the framework-neutral core (model, geometry, projection, solvers, nested layouts, presets, instrumentation) and the React adapter (provider, components, hooks, interaction, transfer scope).
