# Browser-test port ledger

Gridla was extracted from a larger application whose browser test suites
covered its layout engine. Every one of those tests was reviewed and given
exactly one disposition:

- **ported-core** — the behaviour is deterministic layout math (move, resize,
  place, project, nest). It belongs in a `bun test` suite under
  `tests/compatibility/`. "Covered" means an existing case already pins it;
  "new core case needed" means one must be added.
- **ported-react-or-studio** — the behaviour needs a real pointer, keyboard or
  DOM (previews, handles, pointer capture, selection). It becomes a Playwright
  test against a gallery demo or the studio example. Each row carries a
  setup / action / assertion spec, and the same rows are listed in
  `scenarios.json` for generating spec files.
- **not-applicable** — application-specific (routing, menus, business
  content, page sharing, tabbed-container internals, detached/floating items).
  Recorded with a reason so nothing is silently dropped.

Ids are stable: `B-` regression suite, `C-` canvas suite, `M-` two-row move
suite. Descriptions are neutral rewrites, not source titles.
